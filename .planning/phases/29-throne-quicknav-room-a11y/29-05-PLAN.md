## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → get_throne_growth_state | Authenticated server fn; rejects unauthenticated with ServerFnError. Reads only the session user's ranked data + the user's own team's counts. |
| browser → asset URL (region) | `region` is server-set from InitialTheme (cookie-derived), never a URL/query param — only interpolated into `/img/rooms/throne/{region}/...`. |
| browser → redirect routes | The three redirect targets are static literal strings (`/throne?tab=...`); no user-controlled redirect destination. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|

| T-29-05-02 | Information Disclosure | progression axis | mitigate | `get_latest_ranked_snapshot(&surreal, &user.id, ...)` scopes to the authenticated user's id only; no user-id parameter accepted — no cross-user ranked read. |
| T-29-05-03 | Tampering | region in asset path | mitigate | `region` comes from InitialTheme (server-set cookie), not a URL/query param; only `format!("/img/rooms/throne/{region}/...")` with the resolved value (no path traversal surface). |
