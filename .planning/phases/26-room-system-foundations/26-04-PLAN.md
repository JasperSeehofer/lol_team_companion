<threat_model>
No new attack surface — internal component only. `RoomSurface` makes no server calls, holds only local UI state, and reads only the `?tab=` URL param (used solely to select which already-rendered surface is visible). The `?tab=` value is resolved against a fixed allowlist of tab ids and falls back to the first tab on any unknown value, so a crafted query string cannot select an out-of-contract surface or inject markup. No PII, no DB, no privileged action.
</threat_model>
