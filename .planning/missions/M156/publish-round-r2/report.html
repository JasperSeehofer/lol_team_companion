Scout spike: findings (M156 half C)

Two runs of one of Jasper's own replays, about 32 minutes. v1: Windows HDR on, square Data Dragon portraits (kept as the HDR baseline). v2: HDR off, base circle icons; the run of record. Full text: docs/scout-findings.md. The plots and strips below are derived from the run and are not in git.

Route for the Scout product round

Recommended: A+B, with B on key windows (a written override of the rule, which gives B-first because A is not GO and B is).

B cannot be the primary source for a whole game: one recording per Windows sign-in, endTime ignored, so each 5-minute window costs about 30 s of wall time plus a sign-out and sign-in (about seven for a full game). A is the only full-game source, and its PARTIAL is inflated by the identity bug K, now fixed. The validation run confirms or reverses this.

Time per game: minimap pass at 8× ≈ game length ÷ 7.9 (about 4 min); each top-down window ≈ 30 s + a sign-in.
