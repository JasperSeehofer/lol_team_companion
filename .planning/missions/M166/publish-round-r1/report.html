Wednesday: navgrid and Scout run

M166 · about 2 hours · PowerShell in the lol_team_companion folder · WireGuard tunnel to brain up. Copy each block as it is.

  • Keep the League client closed for steps 1 to 5. The navgrid read refuses to run while it is open.
  • Picked "Wait for Riot" on the card? Do step 1, then skip steps 2 to 5 and start at step 6.
  • Skip step 9 this time. The weights check could not run on brain (only 2 GB of memory free, it needs 3 GB), so nothing is waiting there. Download yolov12.pt from Google Drive as CHECKLIST step 3 says.
  • Run data goes to brain only (step 22, session send). Never git push it: the repo is public.
  • If the Scout prep did not land on the branch (the scout.session commands are unknown), follow tools\scout\CHECKLIST.md as it was.

Navgrid (League client closed)

  1. 1Install Python 3.12 (once). 
    winget install Python.Python.3.12

    If it fails: run py -0; if 3.12 is already listed, go on.

  2. 2Get the navgrid branch. 
    git fetch origin; git switch mission/M166-scout-half-c-and-navgrid-prep; git pull --ff-only

    If it fails: run git status; commit or stash local changes first, then repeat.

  3. 3Make the navgrid venv. 
    py -3.12 -m venv tools\navgrid\.venv; .\tools\navgrid\.venv\Scripts\pip install -e tools/navgrid

    If it fails: py -0 must list 3.12; rerun the pip part with -v and note the error.

  4. 4Read the map file once (prints at most 8 lines and the next scp line). 
    .\tools\navgrid\.venv\Scripts\python -m navgrid pc-run

    If it fails: "client running" means close League fully; "WAD not found" means add --wad "<path to Map11.wad.client>". Running it a second time moves the earlier output to navgrid\previous\.

  5. 5Send the folder to brain. The first scp asks to accept brain's host key: type yes. 
    scp -r "$env:LOCALAPPDATA\navgrid\latest" ops@10.44.0.1:.local/share/navgrid/inbox/

    If it fails: check the WireGuard tunnel is up (ping 10.44.0.1), then repeat. Never put this folder in git.

Scout run

  1. 6Get the Scout branch. 
    git switch mission/M156-scout-replay-spike; git pull --ff-only

    If it fails: run git fetch origin first (needed if you skipped step 2), then repeat.

  2. 7Make the Scout venv. 
    py -3.12 -m venv tools\scout\.venv; .\tools\scout\.venv\Scripts\pip install -e "tools/scout[yolo]"

    If it fails: rerun the pip part with -v; if [yolo] will not install, use tools/scout without it (the template detector still works).

  3. 8Start the run (put your match id from the match history in place of <gameId>). 
    .\tools\scout\.venv\Scripts\python -m scout.session start EUW1_<gameId>

    If it fails: "No module named scout.session" means the prep did not land: follow CHECKLIST.md as it was.

  4. 9Get the weights from brain. skip this time 
    scp ops@10.44.0.1:.cache/scout/models/yolov12.pt tools\scout\models\yolov12.pt

    Instead: download yolov12.pt (227 MB) from the Google Drive link in tools\scout\vendor\pyLoL\README.md into tools\scout\models\ (CHECKLIST step 3). If that fails: skip it; the minimap step uses the template detector alone.

  5. 10Switch on the Replay API. 
    .\tools\scout\.venv\Scripts\python -m scout.session enable-api

    If it fails: add --cfg "<your League folder>\Config\game.cfg"; untick read-only in the file's Properties.

  6. 11Restart the League client and open the replay in borderless full screen on the main monitor. by hand

    If it fails: the replay must be from the current patch; download it again from the match history.

  7. 12Probe the client, hands off (about 3 minutes). 
    .\tools\scout\.venv\Scripts\python -m scout.session probe

    If it fails: open https://127.0.0.1:2999/replay/game in a browser; no answer means the replay is not open or step 10 did not take.

  8. 13Track the minimap, hands off (game length divided by 8). 
    .\tools\scout\.venv\Scripts\python -m scout.session minimap

    If it fails: if the first PNG in frames_minimap is not exactly the minimap, read its left, top, width, height in probe_minimap_only.png with Paint and add --minimap-box L,T,W,H.

  9. 14Sign out of Windows and back in, then reopen the replay. by hand

    If it fails: nothing is lost; the driver remembers the run. Reopen the replay and go on.

  10. 15Track the top-down view (about 8 minutes). 
    .\tools\scout\.venv\Scripts\python -m scout.session topdown

    If it fails: add --keystroke-unlock (press Ctrl+Shift+Y and zoom out when asked).

  11. 16Set the key for this window only. Type your development key at the prompt, never the production key; typed this way it never lands in PowerShell history. 
    $env:RIOT_API_KEY = Read-Host "Riot key"

    If it fails: regenerate the development key in the Riot developer portal and type it again.

  12. 17Fetch the timeline (the match file is saved without player identifiers). 
    .\tools\scout\.venv\Scripts\python -m scout.session timeline

    If it fails: HTTP 403 means the key expired (redo step 16); 404 means a wrong match id.

  13. 18Clear the key. 
    Remove-Item Env:RIOT_API_KEY

    If it fails: close this PowerShell window; the key goes with it.

  14. 19Score the run. 
    .\tools\scout\.venv\Scripts\python -m scout.session score

    If it fails: note the error and go on; brain scores the run again from the sent files.

  15. 20Open the hand check; per row, jump the replay to the time and write yes or no, then save. 
    .\tools\scout\.venv\Scripts\python -m scout.session handcheck

    If it fails: open handcheck.csv in the run folder with Notepad yourself. Fewer than 10 rows is fine.

  16. 21Check the run folder (at most 50 MB, no video, no key, no player identifiers). 
    .\tools\scout\.venv\Scripts\python -m scout.session check

    If it fails: delete the largest PNGs in frames_topdown and run it again.

  17. 22Send the run to brain, never to GitHub. 
    .\tools\scout\.venv\Scripts\python -m scout.session send

    If it fails: check the tunnel and repeat; it refuses a run that fails step 21, so fix that first. Add --dry-run to see the scp line.

Afterwards you can delete %TEMP%\scout-rec and %TEMP%\scout-frames. That's all: the agent takes it from here.
