# Lock-in and stamp prototypes (M151 R0, gallery only)

**Lock-in** (`lockin.html`, `window.lockIn()`): a `.lockbar` span (absolute, `left/right/bottom: -1px`, `height: 2px`, `background: var(--color-outline)`, `transform-origin: left`, `right` in the red column) sits on the slot's bottom hairline. `[data-locked="anim"] .lockbar { animation: lock-draw var(--dur-3) var(--ease-out) both, lock-cool var(--dur-2) var(--ease-out) 620ms both }` with `lock-draw: scaleX(0) -> scaleX(1)` and `lock-cool: background-color accent -> outline` (220 draw + 400 hold, then 160 fade). `[data-locked="anim"] .role { animation: mark-settle var(--dur-3) var(--ease-out) both }`, `mark-settle: translateY(2px), opacity 0 -> none, 1`. `data-locked="instant"` (a lock-in < 1 s after the previous one) and `prefers-reduced-motion: reduce` set `animation: none`: the bar is drawn full width in `outline` at once and the mark is in place. The reduced-motion rule needs `animation: none`, not just the global 0.01 ms rule, because that rule keeps the 620 ms delay.

**Port to `ui::DraftBoard` (R1):** in the pick-cell branch of `cell()` (draft.rs about line 590), add `<span class="lock-bar pointer-events-none absolute -inset-x-px -bottom-px h-0.5 origin-left bg-outline" aria-hidden="true">` (`origin-right` for red), and on the slot `data-locked="anim"|"instant"` from a board-level `lock: RwSignal<Option<(usize, bool)>>` that `DraftState::fill` sets for pick slots only (never bans, moves, swaps, undo or a loaded draft), with `instant = now - last_lock < 1000 ms` (`js_sys::Date::now()`, already a dependency). Put the three `@keyframes` and the two `[data-locked=anim]` rules in `input.css` `@layer components`, with a `motion-reduce` rule setting `animation: none`. `RoleLabel` needs no change: the rule targets `[data-role]` inside the slot. No new dependencies, no JS animation library. Clear `data-locked` when the slot empties.

**Stamp** (`stamp.html`, `window.stamp()`): proposed `GlyphSize::Lg`: 64 px square (80 px from `md`), radius 0, Familjen 600 at 40/48 px; Win `bg-win border-win text-win-ink`, Loss `border-[1.5px] border-loss text-loss`, no fill. **Conflict to settle:** the recipe card says "Motion: none; present at first paint", while the brief asked for a stamp "drawn once". The page follows the card at load; `stamp()` replays a candidate entrance (`stamp-in: opacity 0 -> 1` on the square, `stamp-letter: translateY(2px) -> none` on the letter, 160 ms `--dur-2` `--ease-out`, no scale, no rotation; reduced motion: none). Recommendation: ship R1 static, as the card says, unless the director overrides.
